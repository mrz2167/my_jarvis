# PLAN.md — Jarvis Ecosystem: Roadmap & Architecture

## 🌐 Общая экосистема

```
┌─────────────────────────────────────────────────────┐
│                   JARVIS ECOSYSTEM                  │
│                                                     │
│  ┌──────────────┐        ┌──────────────────────┐   │
│  │  Ghost Touch │        │     Jarvis Agent     │   │
│  │  (Python)    │◄──────►│  C++ Core + Python   │   │
│  │  Hand gesture│  IPC   │  Voice + AI + System │   │
│  │  control     │        │  Commands            │   │
│  └──────────────┘        └──────────────────────┘   │
│         ↑                          ↑                │
│         └──────────── GUI ─────────┘                │
│                  (Desktop App)                      │
└─────────────────────────────────────────────────────┘
```

Два независимых сервиса, одна экосистема.  
Jarvis управляет Ghost Touch через команду вкл/выкл.

---

## 📦 Архитектура Jarvis

```
jarvis/
├── core/              ← C++ движок (офлайн, всегда работает)
│   ├── audio/         ← захват микрофона
│   ├── wake/          ← wake-word детектор
│   ├── stt/           ← Whisper.cpp (речь → текст)
│   ├── tts/           ← Piper (текст → голос)
│   ├── classifier/    ← системная команда или LLM запрос?
│   ├── commands/      ← исполнитель системных команд
│   └── ipc/           ← WebSocket сервер (порт 9712)
│
├── agent/             ← Python агент (онлайн)
│   ├── llm/           ← абстракция над LLM провайдерами
│   │   ├── openai.py
│   │   ├── anthropic.py
│   │   ├── gemini.py
│   │   └── ollama.py  ← локальный LLM (офлайн опция)
│   ├── memory/        ← контекст диалога
│   ├── tools/         ← инструменты агента
│   └── api.py         ← REST/WebSocket сервер
│
├── gui/               ← Desktop приложение
│   ├── frontend/      ← Svelte / React
│   └── src-tauri/     ← Tauri оболочка
│
└── config/            ← настройки пользователя
    ├── commands/      ← пользовательские команды (.toml)
    ├── profiles/      ← режимы (work/game/film/relax)
    └── settings.toml  ← API ключи, язык, голос и т.д.
```

## 🔄 Как всё работает вместе

```
Микрофон
   ↓
[C++ Wake-word] → ждёт "Джарвис"
   ↓ активация
[C++ STT Whisper] → текст
   ↓
[C++ Classifier]
   ↓              ↓
Системная       LLM запрос
команда            ↓
   ↓         [Python Agent]
Выполнить          ↓
напрямую     [LLM API / Ollama]
   ↓              ↓
[C++ TTS Piper] ← ответ текстом
   ↓
Голосовой ответ
```

- [ ] Выбор устройства ввода
- [ ] VAD (Voice Activity Detection) — детектор голоса

#### 1.2 Wake-word
- [ ] Интеграция Whisper.cpp tiny модели для wake-word
- [ ] Настраиваемое слово активации
- [ ] Порог чувствительности

#### 1.3 STT — распознавание речи
- [ ] Интеграция Whisper.cpp (base модель)
- [ ] Поддержка языков: ru / en / uk
- [ ] Стриминг распознавания (не ждать конца фразы)

#### 1.4 Классификатор команд
- [ ] Системная команда → выполнить локально
- [ ] Неизвестный запрос → передать Python агенту
- [ ] Конфиг команд через `.toml` файлы

#### 1.5 Системные команды (офлайн)
- [ ] Управление приложениями: open / close
- [ ] Медиа: play / stop / next / back / volume
- [ ] Режимы: work / game / film / relax

#### 1.6 TTS — голосовой ответ
- [ ] Интеграция Piper TTS
- [ ] Несколько голосов на выбор
- [ ] Поддержка ru / en

#### 1.7 IPC сервер

- [ ] Протокол сообщений: команды, статус, события

## 🛠️ Технологический стек

| Компонент | Технология | Причина |
|---|---|---|
| Движок | C++ | Минимальная нагрузка, нативная интеграция с Whisper/Piper |
| STT | Whisper.cpp (tiny/base) | Лучшее качество офлайн, лёгкий |
| TTS | Piper | Быстрый, офлайн, много голосов |
| Wake-word | Whisper.cpp tiny | Одна библиотека для всего аудио |
| Агент | Python 3.11+ | Богатая экосистема LLM SDK |
| LLM абстракция | LangChain / самописный | Единый интерфейс для всех API |
| GUI | Tauri + Svelte | Лёгкий, нативный, знакомый стек |
| IPC | WebSocket | Уже проверено в Jarvis |
| Конфиги | TOML | Читаемо, просто |
| Ghost Touch | Python | Отдельный сервис, своя кодовая база |

---

## ⚡ Принципы разработки

1. **Офлайн прежде всего** — движок никогда не требует интернета
2. **Минимальная нагрузка** — tiny модели, эффективный код
3. **Модульность** — каждый компонент можно заменить
4. **Пользователь приносит свой API** — мы не храним ключи
5. **Ghost Touch = отдельный сервис** — Jarvis только управляет им
