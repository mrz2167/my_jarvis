# MasterPi RPi — GPIO Map

## Физическая схема (BCM нумерация)

```
                    RPi 40-pin Header
                    ┌────────────────┐
              3.3V  │  1 ●  ● 2 │ 5V
     I2C SDA BCM2  │  3 ●  ● 4 │ 5V
     I2C SCL BCM3  │  5 ●  ● 6 │ GND
         FREE BCM4  │  7 ●  ● 8 │ BCM14  FREE (UART TX)
               GND  │  9 ●  ●10 │ BCM15  FREE (UART RX)
        FREE BCM17  │ 11 ●  ●12 │ BCM18  I2S BCLK (микрофон/динамик)
        FREE BCM27  │ 13 ●  ●14 │ GND
        FREE BCM22  │ 15 ●  ●16 │ BCM23  Кнопка MODE
              3.3V  │ 17 ●  ●18 │ BCM24  FREE
  FREE SPI0 BCM10  │ 19 ●  ●20 │ GND
   FREE SPI0 BCM9  │ 21 ●  ●22 │ BCM25  FREE
  FREE SPI0 BCM11  │ 23 ●  ●24 │ BCM8   FREE SPI0 CE0
               GND  │ 25 ●  ●26 │ BCM7   FREE SPI0 CE1
    I2C ID BCM0 *  │ 27 ●  ●28 │ BCM1   I2C ID *
        FREE BCM5  │ 29 ●  ●30 │ GND
        FREE BCM6  │ 31 ●  ●32 │ BCM12  FREE
   Buzzer BCM6 **  │ 31 ●  ●33 │ BCM13  Кнопка STOP
 I2S LRCLK BCM19  │ 35 ●  ●34 │ GND
   I2S RX  BCM20  │ 38 ●  ●36 │ BCM16  FREE
        FREE BCM26 │ 37 ●  ●38 │ BCM20  I2S RX (INMP441 DATA)
               GND  │ 39 ●  ●40 │ BCM21  I2S TX (MAX98357A DATA)
                    └────────────────┘
```
> \* BCM0/1 — зарезервированы для EEPROM HAT ID, лучше не трогать
> \*\* Buzzer на физическом пине 31 = BCM6

## I2C устройства (шина BCM2/BCM3)

| Адрес | Устройство | Функция |
|-------|-----------|---------|
| 0x7A | MasterPi плата | 6 сервоприводов + 4 мотора |
| 0x77 | Сонар HC-SR04 (I2C версия) | Расстояние до препятствия |

## Подключения (не GPIO)

| Интерфейс | Устройство |
|-----------|-----------|
| USB | Камера (640x480, USB) |
| 5V/GND | Кулер (прямое питание, без управления) |
| MicroSD | ОС Raspberry Pi OS |

## Запланированная плата расширения

```
INMP441 (микрофон I2S):
  VDD  → 3.3V
  GND  → GND
  SD   → BCM20 (пин 38)
  WS   → BCM19 (пин 35)
  SCK  → BCM18 (пин 12)
  L/R  → GND (левый канал)

MAX98357A (динамик I2S):
  VIN  → 5V
  GND  → GND
  DIN  → BCM21 (пин 40)
  BCLK → BCM18 (пин 12)
  LRC  → BCM19 (пин 35)
```
